# Decision Outbox

This folder is for resolved decisions after the human Product Owner, Architect, or QA has responded to a true consent blocker.

Codex may use this folder to preserve accepted, rejected, or superseded Decision Packets once the corresponding `99-decision-inbox/open-decisions.md` row is updated.

Routine delegated decisions do not belong here; they should remain in the normal requirement, QA, architecture, summary, and acceptance-packet files.
