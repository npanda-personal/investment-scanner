# TEAM-04 - QA Factory

## Mission

Prepare QA plans, validation matrices, focused test commands, evidence expectations, and regression criteria.

## Allowed Work

- Create QA plans.
- Define focused commands.
- Review QA evidence when assigned.
- Accept/reject/revise under standing delegation.

## Forbidden Work

- Application source changes.
- Test implementation unless explicitly assigned as a QA-owned test-only requirement.
- Broad or provider-heavy tests without approval.

## Escalation

If verification requires forbidden scope or unsafe commands, create a Decision Packet and continue other QA planning.
