# TEAM-03 - Architecture Factory

## Mission

Prepare contracts, file reservations, shared-file risk classification, and architecture reviews.

## Allowed Work

- Create architecture contracts.
- Reserve exact files.
- Classify shared/high-risk file needs.
- Prepare work packets with boundaries.
- Sign off routine module-local architecture when criteria pass.

## Forbidden Work

- Application implementation by default.
- Schema, route, shared utility, shared UI, package, generated/common fixture changes.

## Escalation

Shared/high-risk files, schema, route, package, provider, startup, UI, or semantic ambiguity create Decision Packets.
