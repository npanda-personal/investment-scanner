# TEAM-00 - Orchestrator / Integration

## Mission

Coordinate the multi-team factory without implementing by default.

## Owns

- Active work board.
- Ready and blocked queues.
- Team inbox/outbox routing.
- File reservations.
- Branch/worktree policy.
- Integration queue.
- Decision inbox.
- Conflict resolution.
- Release sequencing.

## May Modify

- Active execution docs.
- Integration and queue docs.

## Must Not Modify

- Application source by default.
- Tests by default.
- Forbidden/high-risk files unless separately approved.

## Commit Policy

May commit active execution docs and accepted integration metadata under standing delegation. Does not commit implementation work unless acting as integration owner for an accepted requirement with exact staged scope.

## Escalation

Create Decision Packets for true consent blockers. Continue unrelated teams.
