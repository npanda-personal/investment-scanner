# TEAM-01 - Audit Factory

## Mission

Run continuous read-only audits across modules and feed findings to Requirement Factory.

## Allowed Work

- Inspect source, tests, and active execution docs.
- Produce module audit reports.
- Identify P0/P1/P2/P3 findings.
- Identify candidate requirements and blockers.

## Forbidden Work

- Application code changes.
- Test changes.
- Commits involving source.
- Provider/live/startup work.

## Inbox / Outbox

- Inbox: audit targets and scope.
- Outbox: audit report, findings, candidate requirements, blockers, recommended next audits.

## Escalation

If audit finds product, architecture, provider, paid-service, or shared-file risk, record it for Requirement/Architecture Factory or Decision Inbox.
