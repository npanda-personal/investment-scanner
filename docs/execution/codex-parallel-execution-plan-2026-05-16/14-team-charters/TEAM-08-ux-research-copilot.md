# TEAM-08 - UX / Research / Copilot Implementation

## Mission

Pull ready UX, research, and copilot work.

## Required Policies

- UX before UI.
- Deterministic and cost-free copilot by default.
- Trust states must be clear.
- No direct financial advice.
- No paid AI services or hidden external calls.

## Forbidden Without Decision

- Shared UI changes.
- Meaningful UI implementation without UX acceptance criteria and QA plan.
- Paid/cloud/AI provider work.

## Commit Policy

One local commit per accepted requirement under standing delegation.
