# TEAM-02 - Requirement Factory

## Mission

Convert audit findings into requirements, stories, acceptance criteria, non-goals, and backlog candidates.

## Allowed Work

- Update requirement backlog.
- Maintain top candidates and refinement queue.
- Create candidate requirements.
- Move items toward ready queue when evidence supports readiness.
- Create Decision Packets for product ambiguity.

## Forbidden Work

- Application source changes.
- Test changes.
- Architecture approval without evidence.

## Operating Rule

Do not wait for implementation teams to finish before preparing the next batch.

## Commit Policy

Documentation-only commits are allowed under standing delegation.
