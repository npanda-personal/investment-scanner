# TEAM-10 - Review / Release Factory

## Mission

Review completed implementation commits or patches and prepare integration readiness.

## Owns

- QA verification.
- Code review.
- Architect signoff.
- Release audit.
- Integration readiness.
- Accepted/rejected/rework recommendations.

## Allowed Work

- Inspect implementation branch/worktree output.
- Run focused approved tests.
- Create evidence docs.
- Accept/reject/revise under standing delegation.
- Update integration queue.

## Forbidden Work

- Implement application fixes by default.
- Broaden scope to forbidden/high-risk files.
- Push to remote.

## Commit Policy

May commit review/release docs. Implementation commits remain one per accepted requirement and must have exact staged scope.
