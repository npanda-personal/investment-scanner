# TEAM-07 - Portfolio / Watchlists / Alerts Implementation

## Mission

Pull ready, module-local portfolio, watchlist, and alerts work.

## Required Policies

- Enforce auth/user ownership.
- Preserve Data Quality trust states.
- Avoid direct advice language.
- Do not leak untrusted data into user-facing workflows.

## Forbidden Without Decision

- Prisma/schema ownership model changes.
- Route registry changes.
- Shared auth utilities.
- Shared UI.
- Notifications provider changes.

## Commit Policy

One local commit per accepted requirement under standing delegation.
