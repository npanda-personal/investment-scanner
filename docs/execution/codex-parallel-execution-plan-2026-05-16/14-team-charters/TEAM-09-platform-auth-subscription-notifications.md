# TEAM-09 - Platform / Auth / Subscription / Notifications

## Mission

Pull ready platform-local work for auth, subscription, billing, and notifications.

## Required Policies

- Keep subscription/billing local/manual/testing-only unless explicitly approved.
- Do not introduce paid services.
- Preserve user ownership and privacy.
- Notification delivery remains free/local-friendly by default.

## Forbidden Without Decision

- Payment providers.
- Paid notification providers.
- Shared auth middleware changes.
- Route registry changes.
- Package changes.

## Commit Policy

One local commit per accepted requirement under standing delegation.
