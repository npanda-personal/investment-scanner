# Active Work Board

Use this file as the live source of truth for active Codex-agent work. The Senior Fullstack Lead / Orchestrator owns updates to this board unless a work packet explicitly assigns a section to another role.

## Board Rules

- Update this board when a work item changes state, owner, operating mode, priority, blocker status, or GitHub check-in status.
- No implementation starts until the item has a product brief, architecture contract, QA plan, Orchestrator work packet, WIP clearance, assigned lane, one directly responsible developer, reserved write scope, and state `Ready for Implementation`.
- Each lane developer may have only one `In Implementation` or rejected `Needs Revision` item.
- Rejected items stay on the same row and move to `Needs Revision`; the responsible owner fixes that item before pulling new work.
- Product Owner priority changes must update the affected row before downstream agents continue.
- Released items must include GitHub check-in evidence.
