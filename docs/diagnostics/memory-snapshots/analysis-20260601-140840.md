- Baseline working set: 1578.64 MB

`Memory Compression` grew by 909.22 MB working set but only 2.05 MB private memory. Treat that as a pressure symptom, not the root owner of the memory.

## Current Working Hypothesis

The +1.92 GB increase since baseline is mainly explained by:

1. Browser process groups that were not present in the baseline: Chrome and Brave.
2. Duplicate frontend dev-server stacks: two Vite servers plus two esbuild services.
3. Growth in the VS Code process group.

The app-specific part visible in this snapshot is the duplicate frontend dev-server stack. It does not fully explain a 95% spike by itself, but repeated starts of frontend/backend servers, browser sessions, or UI test runs could stack quickly on a 16 GB machine.
