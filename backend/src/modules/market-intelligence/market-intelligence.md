# Market Intelligence

Backend-only persisted read models for trader-facing Market Intelligence pages.

## Stock Interest Snapshot

`GET /api/v1/market-intelligence/stock-interest` reads the latest persisted `StockInterestSnapshot` rows for the requested `region` and `assetType`.

The API does not calculate rankings during the request. Snapshot rows are generated by the `STOCK_INTEREST_REFRESH` pipeline command from local persisted data only:

- `PriceTick`
- `LatestPrice`
- `MarketDeliverySnapshot`
- `Fundamental`
- stock sector metadata

No external provider calls, market-data ingestion, or frontend writes are part of this module.
